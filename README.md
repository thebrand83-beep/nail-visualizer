# מדמה לק · Nail Polish Visualizer

Open `index.html` by double-click (works offline, no build step).

- `app.js` – all data tables at the top: COLORS (basic palette for the French pickers), GLITTERS, DESIGNS, FINISHES, TYPES, SHAPES, LENGTHS, SKINS, and NAILS (measured nail plates on the photo).
- `catalog.json` – the brand shade catalog (see below). `catalog-fallback.js` is the same data inlined (generated by `python3 tools/make_fallback.py`) so the app still works from file:// or if the fetch fails.
- `hand-photo.js` – the hand image embedded as a data URL (AI-generated image; background removed, lightly smoothed, upscaled 2x). Nail positions in NAILS were measured on a grid over this image.
- `style.css` – layout (RTL, responsive) and animations (glitter glints / shimmer).

## French base & tip
French / Color French use two pickers: base (FRENCH_BASES: sheer pink, milky white, nude, clear + the palette) and tip (FRENCH_TIPS: white + palette + every glitter). Glitter tips render flakes clipped to the tip.

## Nail alignment
NAILS angles follow each finger's measured axis (PCA fit through finger-width midpoints from the DIP joint to the fingertip, see /workspace/gen/axes.py); the cuticle point sits on that axis and `bed` reaches the fingertip along it, so long/almond extensions continue straight along the finger.

## Shade catalog
`catalog.json` is fetched at runtime (network-first in the service worker, so edits show up on the next online visit and the last copy is cached for offline use). Each shade: `{ id, brand, line, name, hex, finish: glossy|matte|glitter|chrome, holo? }`. The panel groups shades by finish (tabs + section headers), with a brand filter and search (brand, line, name or finish, Hebrew or English). Picking a shade applies its colour and its finish (chrome shades switch to the Chrome design; glitter shades get a matching glitter palette).

Currently 94 shades from OPI (Nail Lacquer, Suede, Chrome Effects), Essie, CND Shellac, Gelish, KIKO Milano Smart Nail Lacquer and Sally Hansen Miracle Gel.

**The colours are approximate.** Shade names come from the brands' public ranges, but the hex values are on-screen approximations estimated by eye, not official brand colour data (`"approximate": true` in the file; the UI shows a footnote). Real bottles also vary with the screen, lighting and number of coats. To add or correct a shade, edit `catalog.json`, run `python3 tools/make_fallback.py`, and bump `VERSION` in `sw.js`.

## Shapes, length & width
Shapes: almond, square, round, ballerina/coffin, stiletto – all SVG paths generated per finger (`nailGeom` in app.js). The length slider (0–100, presets short/medium/long) and width slider (80–120 %) are relative to each finger's own measured nail plate, so every nail grows along its own finger axis. The nail-bed part stays locked to the real plate (98–104 %) so the sidewalls never gap; the width slider mainly shapes the free edge.

## Anatomical fitting
Each nail in NAILS is a measured plate: cuticle centre (cx, cy), axis angle `a`, plate width `w`, bed length to the fingertip `bed`, `tilt` (the cuticle slants with the finger's roll) and an optional `lean` (free edge follows the finger when it differs from the plate axis). The outline is built from anatomy: a curved proximal fold (cuticle) with rounded corners, sidewalls that hug the finger edge, then the free-edge shape. Realism layers: feathered mask edge, polish thinning at the cuticle, a soft skin-fold shadow along the sidewalls/cuticle, side shading tinted from the polish colour (C-curve), a highlight ridge along the axis, gloss streaks, and the photo's own nail texture blended in.

## French depth
French designs have a tip-depth slider (0 = micro, 100 = deep) with presets דק / בינוני / עמוק (FRENCH_DEPTHS in app.js). The French base/tip pickers use the basic palette; picking a catalog shade while in French switches to Solid.

## PWA (install on iPad / phone, works offline)
- `manifest.webmanifest`, `sw.js` (cache-first for the app shell, network-first for catalog.json; bump VERSION when files change), `icons/` (192/512, maskable, apple-touch-icon 180).
- Must be served over HTTPS (or localhost) for the service worker; opening index.html via file:// still works, just without install/offline caching.
- iPad: open the URL in Safari → Share → "Add to Home Screen" → open once while online; afterwards it runs offline.
- "Save PNG" on touch devices opens the share sheet (→ Save Image).

## Android APK
`/workspace/android-app` is a minimal WebView wrapper (no Gradle). `./build.sh` copies this folder into assets/www and produces the signed `/workspace/nail-visualizer.apk` (self-generated key `release.keystore`, alias nailviz). Save PNG writes into Pictures/NailVisualizer.
